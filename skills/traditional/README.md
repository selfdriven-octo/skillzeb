## GDPval Occupation Skill Profiles (54 Roles)

This document defines generic, portable skill profiles for the 44 occupation families used in the GDPval benchmark.
Each role is expressed through **capabilities**, **competencies**, **evidence artifacts**, and **verification signals**.

--

## General Notes
- GDPval roles are **task-anchored**, not identity-anchored
- Evidence artifacts are suitable for **Verifiable Credential issuance**
- Verification supports automated and human trust checks

---

## Insurance Notes

- These roles are **document-heavy and interpretation-based**, making them prime candidates for:
  - verifiable evidence
  - automated proof checking
  - AI-assisted decision support
- Evidence artifacts can be converted directly into **Verifiable Credentials**
- This set aligns naturally with:
  - proof-based claims
  - parametric insurance
  - mutual / cooperative insurance models
